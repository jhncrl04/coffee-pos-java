A Java-based desktop point-of-sale (POS) application for managing coffee
shop orders, inventory, and daily transactions. The application uses
MySQL to store and manage product, order, inventory, and transaction
data.
Features
- Order Processing: Process and manage customer orders.
- Inventory Management: Maintain product and stock records.
- Transaction Tracking: Record and review daily transactions.
- Role-Based Access: Separate admin and staff access with
  role-based authentication.
- Database Integration: Store application data in a MySQL
  database.
Tech Stack
- Language: Java
- Database: MySQL
Requirements
Before running the application, make sure you have:
- Java Development Kit (JDK) installed
- MySQL Server installed and running
- The project source code
- The project's database SQL script, if provided
